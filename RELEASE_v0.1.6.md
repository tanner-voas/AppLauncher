# AppLauncher v0.1.6 — Persistent mobile navigation

This is a header-only release. The workspace refresh button keeps the same icon throughout update checking/installing and spins while busy; accessible status text reports the phase. The launcher header stays visible when scrolling and respects the iOS safe-area inset. Existing lazy app loading, updates, local storage and host navigation contracts are unchanged.

Apply the individual application patches and push the application repositories before updating AppLauncher submodule pins. AppLauncher still builds the exact commits recorded by its Git submodules; changing this policy is outside this release.
